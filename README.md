## The look and feel

The site was designed to feel warm, bold and playful, like a graph-paper notebook with stickers on it, while staying easy to read.

- **Colors:** rust brown `#833514`, yellow `#F5E283`, navy `#3B5183` and cream `#FEF8EC`.
- **Fonts:** *Annie Use Your Telescope* for the handwritten `yons (ˆ. .ˆ)ʃ` logo, *Grandstander* for the big display headings and *Iosevka Charon* for everything else.
- **Details:** a yellow header with pill-shaped navigation, a graph-paper background, double-outlined headings, a navy profile card, brown label headings and a polka-dot contact section.
- **Little touches:** a floating profile card, drifting polka dots, labels that sweep in, cards that pop in as they scroll into view, and a "Get in touch with me!" heading that slides up from behind the contact box when it is scrolled into view. Visitors who prefer reduced motion get a calm, still version.
- **Every screen size:** the site was designed for both desktop and phone, with a hamburger menu on mobile.

## Behind the scenes

The website is coded with plain **HTML, CSS and JavaScript**: no frameworks, no build tools. It is hosted for free on **GitHub Pages**, so the repository is the website. Every change that is committed here goes live within a minute or two.

```
index.html              Home + Contact
projects-uiux.html      UI/UX & Development projects
projects-graphic.html   Graphic Design projects
projects-data.js        All project content, kept in one place
style.css               Shared styles
projects.css            Project page styles
script.js               Menu and navigation
projects.js             Builds the cards and carousels
assets/                 Images, favicon and CV
```
